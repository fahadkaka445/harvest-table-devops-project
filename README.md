## 🛠️ Tech Stack & DevOps Implementation
- **Cloud Platform:** Amazon Web Services (AWS EC2)
- **Web Server:** Nginx (Virtual Hosting / Custom Server Block)
- **Operating System:** Linux (Ubuntu LTS)
- **Networking & Security:** AWS Security Groups (Port 22 SSH, Port 80 HTTP Inbound Rules)
- **Frontend:** HTML5, CSS3 (Responsive Grid & Flexbox)
---
## 🚀 Key Project Achievements

1. **Infrastructure Provisioning:** Successfully configured and launched an Ubuntu cloud instance on AWS EC2.
2. **Nginx Web Operations:** Purged default configuration blocks and authored custom Virtual Host files pointing to `/var/www/myportfolio`.
3. **Linux System Administration:** Configured folder hierarchies, ownership (`www-data`), file permissions, and daemon reloads via CLI.
4. **Multi-Page Routing:** Designed seamless navigation between `index.html` (Menu) and `about.html` (Story & Contact).
